## Name:Ahmed Abd-Elmohsen — Data Preprocessing & Splitting

**Responsibilities:**

### 1. Image Preprocessing
- Resize all images to a fixed size (128 × 128).
- Normalize pixel values to the range [0, 1].
- Encode animal class labels into numerical values.
- Ensure that images and their corresponding labels are correctly matched.
- Verify that all processed images have consistent dimensions and formats.

### 2. Dataset Splitting
- Split the dataset into three subsets:
  - Training Set: 70%
  - Validation Set: 15%
  - Testing Set: 15%
- Use stratified splitting to maintain class distribution across all subsets.
- Verify that there is no overlap between the three subsets.
- Ensure that the test set remains separate from the training process.

**Deliverables:**
- Image preprocessing code.
- Label encoding implementation.
- Dataset splitting code.
- Prepared Training, Validation, and Testing datasets.
