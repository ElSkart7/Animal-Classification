# Data Team — Dataset Balancing & Preparation

## Ahmed AbdelMohsen — Dataset Collection & Exploration

**Main Responsibility:** Find and collect additional animal images to solve the class imbalance problem in the original Animals-10 dataset.

### Tasks:
1. Analyze the original Animals-10 dataset.
2. Identify the number of images in each of the 10 classes.
3. Identify minority classes (classes with fewer images).
4. Search for additional datasets from sources such as Kaggle and Hugging Face.
5. Collect additional images, focusing mainly on underrepresented classes.
6. Verify that the collected images belong to the correct animal classes.
7. Check image quality and remove corrupted or unreadable images.

### Deliverables:

- Additional datasets and their sources.
- Number of collected images per class.
- Dataset exploration report.

## Menna — Dataset Analysis & Balancing Strategy

**Main Responsibility:** Analyze the original and additional datasets and determine how to balance the 10 classes.

### Tasks:
1. Analyze the distribution of the original dataset.
2. Analyze the distribution of the newly collected images.
3. Compare the number of images in each class before and after adding new data.

## Mohamed Sameh — Data Integration, Cleaning & Preprocessing

**Main Responsibility:** Combine the original and additional datasets and prepare them for model training.

### Tasks:
1. Combine the original dataset with the additional collected images.
2. Standardize class names and label mappings.
3. Remove duplicate images.
4. Remove invalid or corrupted images.
5. Resize all images to 128×128 pixels.
6. Normalize images using the same preprocessing method expected by the model.
7. Split the dataset into:
   - Training: 70%
   - Validation: 15%
   - Testing: 15%
8. Use stratified splitting to preserve class distribution.
9. Ensure there is no overlap or data leakage between the splits.

### Deliverables:
- Dataset integration code.
- Cleaning and preprocessing code.
- Label mapping.
- Prepared training, validation, and testing datasets.
