
An experimental CNN that classifies an image into one of ten animal classes.

## Model

- Architecture: custom CNN with three convolutional blocks, global average pooling, a 64-unit dense layer, and a 10-class softmax output
- Parameters: 102,154
- Framework: TensorFlow/Keras
- Input: RGB image, resized to 128 × 128 pixels
- Preprocessing: convert pixel values to `float32` and divide by 255

## Label Mapping

| **ID** | **Class** |
| ------ | :-------: |
| 0      | Butterfly |
| 1      |    Cat    |
| 2      |  Chicken  |
| 3      |    Cow    |
| 4      |    Dog    |
| 5      |  Elephant |
| 6      |   Horse   |
| 7      |   Sheep   |
| 8      |   Spider  |
| 9      |  Squirrel |

## Training

The model uses Adam and was fine-tuned with a learning rate of `0.0003` and a batch size of `32`. The training split was balanced using oversampling; validation and test splits were not oversampled.

## Results

|  **Metric** | **Validation** | **Test** |
| :---------: | -------------- | -------- |
|   Accuracy  | 74.61%         | 74.76%   |
|     Loss    | 0.7992         | 0.8097   |
|   Macro F1  | 0.720          | 0.725    |
| Weighted F1 | 0.747          | 0.748    |

The test split was evaluated during earlier model-development steps, so the test result should be treated as a development reference, not as a fully independent benchmark.

## Limitations

The model can confuse visually similar classes, especially Cat and Dog, and Cow, Horse, and Sheep. Some predictions were also affected by image backgrounds.



A later manual review found a small number of label and image-quality issues in the training data. This checkpoint was trained before those issues were corrected or excluded, so its metrics may reflect some label noise.



Softmax scores are model outputs and have not been calibrated as confidence probabilities.
